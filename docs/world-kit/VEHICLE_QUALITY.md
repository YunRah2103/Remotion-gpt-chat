# Vehicle quality upgrade

Refine all 35 original generic vehicles for repeated Remotion videos. Retain catalogue identities, proportions, metre scale, shared interior layouts, cutaway options and deterministic wheel/steering interfaces. No real manufacturer designs or new dependencies.

Use rounded tyre profiles, recessed alloy barrels and visible rotors/calipers; layered lamp housings and lenses; modelled grille slats, body seams, mirrors, wipers, exhausts and family-specific hardware. Add upholstery, gauges and console details to the shared interiors. Keep the stylised baseline lightweight enough for software rendering and editable by other agents.

Native stills cover all 35 models; moving review covers seven families. Export and reload every GLB. Existing world/interior/parts tests must remain green.
