# Reusable world kit implementation plan

Goal: deliver reusable generic vehicle variants and matching environments.
Architecture: pure Three.js factories + thin React bindings + isolated Remotion showcases.
Tech stack: existing Three.js, R3F, Remotion and TypeScript; no new dependencies.
Spec: ../specs/2026-10-18-world-kit-design.md

## Constraints
+X forward, +Y up, +Z left. Metres. Tyres rest on y=0. Preserve existing films. Frame-driven animation only. 19 variants, 3 environments.

## Tasks
- [ ] Catalogue and models: tests in tests/world-kit/models.test.mjs; types/catalogue in src/yunex/world-kit/catalog.ts; factories in geometry.ts and vehicles.ts. Verify real bounds, wheel pivots, distinct bodies and valid geometry.
- [ ] Environments and motion: environments.ts and motion.ts, route sampling and instanced repeatable scenery. Test every pairing, deterministic seeds, reverse/steering and circuit seam.
- [ ] React bindings and showcase: components.tsx, Showcase.tsx, index.tsx; separate entrypoint, plus additive root folder. Verify npm run check and native stills/moving frames.
- [ ] Deliver: usage guide, export script, preview gallery, CI and PR. Review actual renders, export GLBs and run tests/check again.

## Review focus
Wheel arch intersections; ground penetration; forward roll sign; circuit direction/seam; transparent glass sorting; distant scenery clipping; real geometry differences among variants; portrait framing for truck; disposal of shared geometry.
