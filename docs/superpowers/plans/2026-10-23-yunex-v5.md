# YUNEX V5 Implementation Plan

**Goal:** Add an opt-in road-led environment studio without changing any V4 models, defaults or EP005 files.
**Architecture:** One arc-length spline supplies ribbon geometry, grade/bank pose, scenery setbacks and deterministic driving. Authored modules supply four flagship locations. V4 hero cars remain intact; V5 vehicle finish and imported-model adapters are separate opt-ins.
**Tech Stack:** Existing Three.js, React, Remotion, Node 24. No new dependencies.
**Spec:** Owner's complete V5 assignment, 23 October 2026.

- [ ] Test route/mesh contact, negative distances, banking, invalid settings, seek determinism and preserved catalogue.
- [ ] Implement validated structured config, spline roads with shoulders/kerbs/markings and local height samples.
- [ ] Build terrain, instanced natural scenery and modular city/circuit architecture for four presets.
- [ ] Add deterministic vehicle placement, four driving compositions and structured CLI.
- [ ] Run full existing regressions, TypeScript and render small proof windows; revise from decoded images.
- [ ] Render four 240-frame native portrait masters and controlled legacy/new comparison; full decode, hashes and honest visual report.
- [ ] Commit isolated source, open PR and merge only after CI and visual gates succeed.

Review focus: road edges at high curvature; frame seeking; camera foreground obstruction; wheel contact on grades; night readability. No physically calibrated simulation or photorealism claim.
