# YUNEX — GitHub-hosted YouTube browser screen-recording test

**Date:** 12 October 2026. **Status:** Experiment completed. **Production recommendation:** Do not use this technique to acquire YouTube footage on current GitHub-hosted runners.

## Test design

On a stock GitHub Actions `ubuntu-24.04` runner, launch actual Google Chrome in Xvfb and test two recording implementations:

- **X11/FFmpeg**: capture Chrome's virtual display using `ffmpeg -f x11grab`; 960x540 H.264 at 24fps, six seconds.
- **puppeteer-stream**: capture the actual Chrome browser tab's video and audio via extension and MediaRecorder; remux/re-encode resulting WebM to MP4.
- Known-available **control:** directly hosted *Big Buck Bunny* 30-second MP4, Blender Foundation Creative Commons movie source (used strictly as test media).
- **YouTube watch:** `https://www.youtube.com/watch?v=YE7VzlLtp-4`.
- **YouTube embed:** `https://www.youtube.com/embed/YE7VzlLtp-4?autoplay=1&mute=0&playsinline=1`.
- **YouTube privacy-enhanced embed:** `https://www.youtube-nocookie.com/embed/YE7VzlLtp-4?autoplay=1&mute=0&playsinline=1`.

A success requires the browser HTML5 player to have positive video dimensions, an actual ready video, >1.5 second time progression, a decodable recorded file and at least three differing sampled recorded frames. Capturing a changing browser spinner or interactive error screen is **not** successful YouTube video playback.

## Decision

**Google Chrome can record an actual playing video and audible sound on GitHub Actions.** However, this does **not** help with YouTube when YouTube refuses to play on the cloud runner. This is a playback restriction, not a capture-technology limitation. The exact same test media recorded successfully via a directly hosted MP4 but failed through YouTube's player.

- Keep **direct original MP4, authorised creator/manufacturer assets, verified TikTok and Instagram** as the practical YUNEX source options.
- Do not describe the recorded YouTube error screen as downloaded footage.
- Do not attempt to defeat YouTube authentication or bot challenges. Use footage under applicable rights/permissions.
- Do not claim full HDR is preserved: these demonstrations output 8-bit SDR H.264/VP8 video.
- Test branch **`experiments/youtube-browser-recording-20261012`** is isolated; **main was not changed**.
