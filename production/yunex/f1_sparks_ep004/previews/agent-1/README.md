# YUNEX EP004 Agent 1 — deterministic native Remotion previews

Source adapter: `mechanics/F1HeroVehicle.tsx`. The same `getSkidDescriptors()` positions are consumed by Agent 2 and correspond to the **named discrete metallic skid mesh bottom surfaces**. The nonmetallic composite plank is a separately meshable segmented item surrounding the skid cutouts. Factory wheel roll/steering pivots are preserved.

## Render from repository root (Node 24, `npm ci`)

```bash
npm run check
node --experimental-strip-types --test production/yunex/f1_sparks_ep004/tests/agent-1/*.test.mjs
npx remotion render production/yunex/f1_sparks_ep004/previews/agent-1/entry.tsx EP004A1Underfloor out/ep004/agent1-underfloor.mp4 --gl=swangle --codec=h264 --pixel-format=yuv420p
npx remotion render production/yunex/f1_sparks_ep004/previews/agent-1/entry.tsx EP004A1CarContext out/ep004/agent1-context.mp4 --gl=swangle --codec=h264 --pixel-format=yuv420p
ffprobe -v error -select_streams v:0 -count_frames -show_entries stream=width,height,avg_frame_rate,nb_read_frames,duration -of json out/ep004/agent1-underfloor.mp4
ffprobe -v error -select_streams v:0 -count_frames -show_entries stream=width,height,avg_frame_rate,nb_read_frames,duration -of json out/ep004/agent1-context.mp4
ffmpeg -v error -xerror -i out/ep004/agent1-underfloor.mp4 -f null -
ffmpeg -v error -xerror -i out/ep004/agent1-context.mp4 -f null -
```

Expected metadata only (do NOT report as observed without successful render): underfloor 180 frames / 6s; context 240 frames / 8s; both 1080×1920 at 30fps. Both are complete animated car shots, not stills. Context clip uses the kit track with **provisional flat asphalt**; Agent 4 must replace track geometry to match `shared/track.ts` prior to integrated contact or spark sign-off.

### Preview limitations
- Motion is `sampleAgent1Fixture()`, explicit temporary reference, *not* Agent 2 physics. It follows the kit closed track and samples shared profile for illustration, but this is not evidence of tyre/skid road contact, CFD, lap telemetry, or accurate racing suspension loads.
- Technical cutaway ghosts the *same* factory shell without shifting real skid points, and the underside stage is a deliberately isolated technical environment.
- Material choice represents permitted Ti6Al4V for illustration. FIA permits 17-4PH subject to competition selection; do not say all cars always use titanium.
- Native videos, frame inspection and technical proof must be generated by CI or a workstation with repository dependencies. A PR alone is not video approval.
