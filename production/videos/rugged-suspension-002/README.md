# RUGGED SUSPENSION POLISH 02

Builds directly from `automotive-tests/rugged-suspension-001` source SHA `99fcfbee182ef8adbdad49a870ead7bf2019ca55`.

## Geometry and provenance

The original SUV upper body, doors, bonnet, curved fenders, lamps, window glazing, grille, handholds, cargo rails and underbody are generated by a genuine Blender script and exported to GLB with preserved named part hierarchy. Source `build_blender_suv.py`; generated GLB is an immutable GitHub Actions artifact staged to `public/mechanics/rugged-suv-body-002.glb` for rendering. No external licensed assets, YUNEX content, manufacturer CAD or paid services.

Mechanics, knuckles, tyres, brake assemblies, coil springs and telescoping dampers remain dynamically rendered in Three.js and use mathematically fixed upper/lower arm lengths and fixed knuckle span.

Four-wheel tyre height follows the same terrain field used to build the true 3D trail. Chassis roll, pitch and height are controlled by a damped discrete response, with explicit finite travel limits. Mathematical circle intersections solve a realistic constrained four-bar. Tests check all 600 frames, out-of-travel, ground clearance, spring/damper inverse response, mount rigidity, and wheel rotations. This is an illustrative suspension model, not certified dynamics.

## Rendering/QA

Dedicated source-locked GitHub Actions workflow `.github/workflows/rugged-suspension-002.yml`:
Blender GLB generator/inspection → mechanical and production preflight → native moving proofs → five 120-frame software-WebGL chunks → FFprobe and full FFmpeg decode → verified candidate artifact.

A source build that has green CI but an unreviewed native film is a **candidate**, not a quality approval. Independent visual review is required before release.
