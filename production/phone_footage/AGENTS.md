# S25 V4 — instructions for any AI agent working in this folder

**Do not guess the protocol from filenames or rebuild the service.**

1. **Start with the [YUNEX V4 new-agent quick-start](https://github.com/YunRah2103/Remotion-gpt-chat/blob/main/docs/YUNEX_V4_NEW_AGENT_START_HERE.md)**. The [full V4 agent protocol](https://github.com/YunRah2103/Remotion-gpt-chat/blob/main/docs/YUNEX_S25_V4_AGENT_GUIDE.md) and [worker README](README_V4.md) provide additional detail.
2. Repo is `YunRah2103/Remotion-gpt-chat`; this branch is `experiments/s25-footage-worker-v4-10min-20261012`. Leave the obsolete `yunus-video-lab` untouched. Use **`agent_jobs_v4.py prepare`** for the canonical two-line `YUNEX_PHONE_JOB_V4` payload; it prints but does **not** create an issue.
3. Accepted queue entries are **open issues authored by `YunRah2103`**, title `[YUNEX PHONE JOB] ...`, exact canonical HTTPS YouTube watch URL, valid 2–600 s excerpt and 720p/1080p ceiling for video. `--media video` (MP4) is default; `--media audio` (AAC M4A) is CI-tested but needs first real S25 proof.
4. **No source licence registration is required to queue a review job.** The worker stores unknown-rights sources in **private draft Releases**; do not publish or represent permissions as granted. Prefer accessible legitimate original/direct MP4 downloads when available.
5. **Do not request a Termux reinstall, GitHub token, manual upload, or user re-download.** The phone has already passed real YouTube jobs **[#55](https://github.com/YunRah2103/Remotion-gpt-chat/issues/55)** and **[#56](https://github.com/YunRah2103/Remotion-gpt-chat/issues/56)**. Reuse existing Release assets instead of requeueing them. The loop's runtime status must be checked; queueing cannot remotely start Termux.
6. Read `YUNEX_PHONE_DONE_V4` / `YUNEX_PHONE_FAILED_V4` issue comments. `mp4_url: null` for draft is **expected**; it does **not** mean the file is missing. For private drafts, **`contents: read` failed with HTTP 403**; authenticated GitHub Actions **`permissions: contents: write`** with built-in `${{ github.token }}` successfully downloaded #56 in [run #38441894486](https://github.com/YunRah2103/Remotion-gpt-chat/actions/runs/38441894486). Keep this permission limited to workflows needing draft reads.
7. **Done means actual media bytes, not a queue issue or metadata**: fetch draft asset, match the reported SHA256, FFprobe, full FFmpeg decode, inspect moving video or listen to audio; hand a private, accessible asset/artifact to the appropriate editor and preserve user-approved footage and music.
8. **Do not edit `v4_worker.py`, installer, tests, or source catalogue unless the user explicitly asks for worker maintenance.** Agents assigned footage or editing should work with the existing system and report exact results.

The phone can be paused to save battery. Optimised V4 polls every 120 s by default when running; no claim is made that a remote GitHub job starts Android or that the current phone process has the latest code.
