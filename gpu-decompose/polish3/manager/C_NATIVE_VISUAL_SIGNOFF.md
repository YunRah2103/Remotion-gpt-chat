## Disclosed limitations / conditional release gate
- Exact unseen GPU internals are artistically modeled, not XFX CAD. PCB component placement and fin/pipe layout are indicative.

This is a restrained studio creative choice (no clutter or irrelevant HUD added), not a promise of edge-to-edge hardware. Closer crops would remove physically meaningful exploded components.
- Some heatpipes and actual board chips stay partially obscured behind the real fin stack/shroud; film demonstrates geometry, not an isolated educational teardown of each chip.
- Native moving previews only span 47 sampled frames, not the entire 450-frame sequence. Full frame integrity, text, sound, colour and remaining transitions MUST be checked on final full 15-second MP4.
