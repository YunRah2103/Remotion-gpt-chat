# quality-supercar-coachbuilt

Edit recipe.json. Keep durations in seconds and use kit:catalog for valid assets.

Run from repository root:

`npm run kit:validate -- quality-supercar-coachbuilt`

`npm run kit:preview -- quality-supercar-coachbuilt`

`npm run kit:render -- quality-supercar-coachbuilt`

Narration/music are optional public-relative audio paths; supply original audio yourself. Review every cut and caption before handoff.
